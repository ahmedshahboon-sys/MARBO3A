# MARBO3A official identity

The approved production identity is centralized in this directory.

- `marbo3a-mark.png` — canonical square site/runtime mark.
- `marbo3a-app-icon.png` — application/PWA icon source.
- `marbo3a-maskable.png` — safe-zone maskable icon source.

Runtime UI must use PNG assets for reliable rendering on Android/Chrome/Safari/PWA. The root PWA icons and Apple touch icon are committed derivatives of this same identity. Legacy SVG brand assets are deprecated and should not be used.
