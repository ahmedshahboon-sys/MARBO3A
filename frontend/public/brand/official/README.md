# MARBO3A official brand source

The approved MARBO3A identity is centralized under this directory.

- `marbo3a-mark.svg` is the canonical application/social mark used by the UI, PWA icon generator, OpenGraph rendering, and maintenance gate.
- Raster derivatives (`pwa-192.png`, `pwa-512.png`, `apple-touch-icon.png`, `pwa-maskable-512.png`) are generated at build time from the canonical mark.
- The approved full lockup artwork is retained separately as a source asset and should not be hand-copied into components.

Do not introduce new independent logo artwork elsewhere in the project. All new surfaces must reference the canonical brand assets from this directory.
